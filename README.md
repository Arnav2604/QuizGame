# Python Terminal Quiz Application

A lightweight, interactive command-line quiz application built in pure Python. Test your knowledge across core technical subjects with instant answer validation and a performance summary.

---

## Features

* **Subject Variety**: Built-in quizzes for Python Basics, Data Structures, and Engineering Mathematics.
* **Instant Feedback**: Displays immediate confirmation for correct answers and reveals the correct option when an answer is wrong.
* **Result Breakdown**: Automatically calculates and prints final score, correct answer count, incorrect answer count, and percentage accuracy.
* **Zero Dependencies**: Runs entirely on standard Python 3 with no external libraries required.

---

## Available Topics

* **Python Basics**: Syntax, built-in functions, data types, and file extensions.
* **Data Structures**: Asymptotic time complexity, stack/queue behaviors, and linked list fundamentals.
* **Engineering Math**: Derivatives, logarithms, integrals, factorials, and geometry.
